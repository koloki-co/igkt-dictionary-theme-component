# IGKT setup

IGKT uses the same Multilingual Dictionary theme component as any other forum. Configure it in the theme component settings:

| Setting | IGKT value |
| --- | --- |
| `data_topic_id` | `10327` on IGKT; use the copied topic ID on a local test forum. |
| `page_title` | `IGKT Multilingual Knot Dictionary` |
| `page_subtitle` | `Knots, ropework terms and tools in English, Swedish, German, Finnish, French and Spanish.` |
| `language_order` | `en, sv, de, fi, fr, es` |
| `default_from_language` | `en` |
| `sources_note` | Copy the current approved credit into this setting before switching. It is no longer provided by default. |

Keep the credit for Virittäjä and the other sources, and confirm the wording against their permission and attribution requirements. The [import review](../review.md) records the licence boundary. Do not put the real entries, editorial notes or exports in this repository. Review the data topic's editing permissions separately from who can read it. The existing `igkt-dictionary` fences can stay as they are.
